# FarmaPRED-PEP: Symptom Trajectory Predictor

This Shiny web application provides tools to predict longitudinal symptom trajectory subgroup membership in patients with first-episode psychosis (FEP). The application includes two prediction models: one for positive symptom trajectories and one for negative symptom trajectories over one year of follow-up.


## 🧠 About the Project

This project is part of the FarmaPRED-PEP study, developed by the University of Barcelona, IDIBAPS, and CIBERSAM. It aims to facilitate the application of data-driven prediction models developed to identify distinct longitudinal symptom trajectories in patients with first-episode psychosis.

The models implemented in this application were developed using data from the PEPS cohort and externally validated in the PAFIP cohort. They predict subgroup membership for longitudinal positive and negative symptom trajectories over one year of follow-up.

The study protocol can be found in the [STUDY PROTOCOL article](https://doi.org/10.3389/fpsyt.2024.1497565). More details about the development and external validation of the symptom trajectory prediction models can be found in the [RESEARCH article in preparation](http://www.google.com/).

## 🔧 Usage

You can access and use the application online at the following link:

👉 [Shinny application](https://farmapred-pep.shinyapps.io/predictSymptomTrajectories/)

No installation is required. Simply open the link in your web browser.

ℹ️ **This tool is intended for research purposes only and must not be used for clinical diagnosis or treatment decisions.**
